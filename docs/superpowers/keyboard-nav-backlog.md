# Keyboard Navigation — Future Phases Backlog

Captured during brainstorming (Phase 1 = Navigation only).

## Phase 2 — Selection
- **Cmd+A** — Select all files on current page
- **Shift+↑↓** — Extend selection (range select)
- **Escape** — Deselect all / close modal

## Phase 3 — File Actions (on focused/selected file)
- **Cmd+Delete** — Delete selected file(s) (with confirmation)
- **F** — Toggle favorite on focused file
- **Cmd+L** — Copy direct link (opens direct link modal)
- **Cmd+Shift+S** — Share selected file(s)

## Phase 4 — Global Actions
- **Cmd+Shift+N** — New folder
- **Cmd+U** — Upload
- **?** — Show keyboard shortcuts help overlay
